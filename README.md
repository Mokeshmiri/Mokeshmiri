# Hi, I'm Mo Keshmiri

Junior Software Engineer and Computer Engineering student at Politecnico di Torino.

I enjoy building practical software, reliable backends, data pipelines, and clear interfaces for complex technical systems. My experience spans backend development, embedded telemetry and real-time visualization, and full-stack web applications.

## What I work on

- **Backend and data systems:** Python services, APIs, ETL pipelines, relational databases, and internal tools.
- **Embedded and real-time systems:** telemetry automation and visualization for multidisciplinary engineering teams.
- **Web applications:** full-stack Flask projects and responsive interfaces built with modern frontend tools.
- **Engineering practices:** system integration, testing, CI/CD, Agile collaboration, and maintainable project structure.

## Featured projects

### SilkStep

**Python · Flask · SQLite · Flask-Login · Bootstrap**

A full-stack platform for discovering and booking walking tours in Tehran. Guides manage tours and schedules, participants book available dates, and administrators monitor platform activity.

[View the SilkStep repository](https://github.com/Mokeshmiri/SilkStep)

### Dragon Guild

**Python · Flask · SQLite · Flask-Login · Bootstrap**

A role-based weekly quest-management application with scheduling, capacity controls, overlap validation, authentication, and separate adventurer and guild-master workflows.

[View the Dragon Guild repository](https://github.com/Mokeshmiri/Dragon-guild) · [Open the live demo](https://mokeshmiri.pythonanywhere.com/)

### Maryam Keshmiri — Artist Portfolio

**React · Vite · Tailwind CSS**

A responsive artist portfolio with a grid-based gallery, interactive lightbox, video support, and maintainable component structure.

[Visit maryamkeshmiri.com](https://www.maryamkeshmiri.com/)
